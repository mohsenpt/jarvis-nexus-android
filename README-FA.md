# JARVIS NEXUS — Android build

این نسخه از رابط فعلی جارویس استفاده می‌کند و پل ارتباطی JavaScript به اندروید را فعال کرده است.

## ساخت APK
1. فایل‌های این ZIP را در مخزن `mohsenpt/jarvis-nexus-android` جایگزین کنید.
2. تغییرات را روی شاخه `main` ارسال کنید.
3. در GitHub > Actions اجرای جدید را باز کنید.
4. پس از موفقیت، Artifact با نام `JARVIS-NEXUS-debug-APK` را دانلود و APK داخل آن را نصب کنید.

## قابلیت‌های این نسخه
- اجرای رابط همراه پروژه به‌صورت محلی؛ برای بازشدن رابط اصلی به اینترنت وابسته نیست.
- تشخیص فرمان‌های محلی موجود: ساعت، تاریخ، یادداشت، یادآور و تنظیمات.
- اعلام درصد باتری از طریق API بومی اندروید.
- فرمان تماس با شماره: شماره‌گیر اندروید باز می‌شود؛ تماس را خود کاربر برقرار می‌کند.
- فرمان پیامک با شماره: برنامه پیامک با متن پیشنهادی باز می‌شود؛ ارسال را خود کاربر تأیید می‌کند.
- پاسخ صوتی و تشخیص گفتار داخل برنامه به امکانات WebView و موتور گفتار دستگاه وابسته است.

## محدودیت‌های مهم و صادقانه
- این نسخه هنوز به مدل هوش مصنوعی آنلاین متصل نیست؛ پاسخ‌های آزاد ChatGPT-مانند ندارد.
- عبارت بیدارباش دائمی «Hey Jarvis» هنگام بسته‌بودن برنامه یا خاموشی صفحه در این بسته پیاده‌سازی نشده است. این قابلیت به سرویس بومی foreground، مجوز میکروفون، طراحی مصرف باتری و موتور تشخیص عبارت بیدارباش نیاز دارد و باید جداگانه روی گوشی آزمایش شود.
- تشخیص گفتار آفلاین فارسی به وجود موتور/مدل فارسی روی گوشی وابسته است و تضمین‌شده نیست.
- تماس و پیامک بی‌صدا یا بدون تأیید کاربر انجام نمی‌شود.
- این خروجی APK آزمایشی debug است، نه نسخه انتشار فروشگاهی.
