# JARVIS NEXUS — پروژه اندروید

این پروژه یک پوستهٔ WebView برای سایت فعلی جارویس است و APK آن از طریق GitHub Actions ساخته می‌شود.

## ساخت APK
1. محتوای ZIP را در مخزن GitHub خود با نامی مانند `jarvis-nexus-android` بارگذاری کنید.
2. به زبانهٔ **Actions** بروید.
3. گردش‌کار **Build JARVIS Android APK** را اجرا کنید (یا بعد از push خودکار اجرا می‌شود).
4. در اجرای موفق، از بخش **Artifacts** فایل `JARVIS-NEXUS-debug-APK` را دریافت کنید.

## محدودیت‌های نسخهٔ اول
- برنامه سایت آنلاین را باز می‌کند؛ در صورت خطای اتصال، فایل HTML همراه پروژه را باز می‌کند.
- تماس فقط صفحهٔ شماره‌گیری اندروید را باز می‌کند و پیامک فقط برنامهٔ پیامک را با متن آماده باز می‌کند؛ هیچ تماس یا پیامکی بی‌اجازه ارسال نمی‌شود.
- صفحهٔ HTML فعلی هنوز دکمه‌های تماس و پیامک متصل به پل بومی ندارد؛ این‌ها باید در مرحلهٔ بعد به رابط اضافه شوند.
- پاسخ/رد خودکار تماس ورودی نیازمند پیاده‌سازی جداگانه با مجوزها و نقش‌های خاص اندروید است و در این نسخه وجود ندارد.
- صدا و تشخیص گفتار همچنان به پشتیبانی مرورگر/موتور گفتار دستگاه وابسته است؛ این پوسته به‌تنهایی صدای فارسی آفلاین نصب نمی‌کند.
- این APK برای آزمایش است و امضای انتشار فروشگاهی ندارد.
